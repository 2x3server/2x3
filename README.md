# 2x3

## Descrizione

2x3 è un progetto open source dedicato alla ricostruzione automatica di documenti cartacei distrutti o frammentati.

L'obiettivo è realizzare un sistema modulare capace di:

- acquisire immagini provenienti da scanner o fotocamere;
- individuare automaticamente i frammenti;
- analizzarne forma, orientamento e contenuto;
- ricostruire il documento originale mediante algoritmi di matching;
- esportare il risultato finale.
