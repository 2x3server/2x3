# ROADMAP

**Progetto:** 2x3

**Versione:** Build 0.1

------------------------------------------------------------------------

# Visione del progetto

L'obiettivo di 2x3 è realizzare un'applicazione Open Source capace di
trasformare immagini e video in modelli 3D attraverso una pipeline
modulare, documentata e facilmente estendibile.

Ogni Build dovrà aggiungere funzionalità mantenendo il progetto stabile
e ben documentato.

------------------------------------------------------------------------

# Stato attuale

La Build 0.1 rappresenta la base del progetto.

In questa fase vengono realizzati:

- struttura del repository;
- documentazione iniziale;
- configurazione dell'ambiente di sviluppo;
- codice di avvio;
- primi test.

------------------------------------------------------------------------

# Roadmap

## Build 0.1 — Fondamenta del progetto

Obiettivi:

- completare la documentazione;
- creare il codice iniziale;
- predisporre la pipeline;
- configurare il sistema di log;
- predisporre i test iniziali;
- verificare il corretto funzionamento del progetto.

Risultato atteso:

Una base stabile sulla quale sviluppare tutte le Build future.

------------------------------------------------------------------------

## Build 0.2 — Pipeline di importazione

Obiettivi:

- importazione immagini;
- importazione video;
- verifica dei formati supportati;
- gestione degli errori di caricamento.

Risultato atteso:

L'applicazione è in grado di ricevere correttamente i file di input.

------------------------------------------------------------------------

## Build 0.3 — Elaborazione iniziale

Obiettivi:

- preparazione dei dati;
- normalizzazione dei file;
- gestione della pipeline interna.

Risultato atteso:

I dati sono pronti per essere elaborati dai moduli di ricostruzione.

------------------------------------------------------------------------

## Build 0.4 — Primo motore di ricostruzione 3D

Obiettivi:

- integrazione del primo motore Open Source;
- generazione dei primi modelli 3D;
- gestione dell'esportazione.

Risultato atteso:

Prima conversione completa da immagine o video a modello 3D.

------------------------------------------------------------------------

## Build 0.5 — Interfaccia grafica

Obiettivi:

- prima GUI;
- gestione dell'importazione tramite interfaccia;
- visualizzazione dello stato della pipeline.

Risultato atteso:

L'applicazione diventa utilizzabile senza operazioni manuali sul
progetto.

------------------------------------------------------------------------

## Build 0.6 e successive

Le Build successive saranno dedicate a:

- miglioramento della qualità dei modelli 3D;
- ottimizzazione delle prestazioni;
- integrazione di nuovi strumenti Open Source;
- miglioramento della GUI;
- aumento della copertura dei test;
- preparazione della prima versione pubblica.

------------------------------------------------------------------------

# Regole operative

Ogni Build dovrà comprendere:

- aggiornamento della documentazione;
- aggiornamento del codice;
- aggiornamento dei test;
- verifica del progetto;
- report finale della Build.

Una Build viene considerata completata solo quando tutta la
documentazione e il codice risultano coerenti tra loro.

------------------------------------------------------------------------

# Obiettivo finale

Realizzare un'applicazione Open Source, modulare e facilmente
estendibile che permetta la conversione di immagini e video in modelli
3D mantenendo una struttura stabile nel tempo.
