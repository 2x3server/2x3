# DECISIONS

**Progetto:** 2x3

**Versione:** Build 0.1

------------------------------------------------------------------------

# Decisioni Architetturali

## D-001 — Linguaggio di sviluppo

**Decisione**

Utilizzare Python come linguaggio principale del progetto.

**Motivazione**

Python offre un ecosistema maturo per l'elaborazione di immagini, OCR, intelligenza artificiale e sviluppo multipiattaforma.

------------------------------------------------------------------------

## D-002 — Interfaccia grafica

**Decisione**

Realizzare una GUI desktop semplice e modulare.

**Motivazione**

L'applicazione deve poter essere utilizzata anche da utenti senza competenze tecniche.

------------------------------------------------------------------------

## D-003 — Architettura modulare

**Decisione**

Suddividere il progetto in moduli indipendenti.

**Motivazione**

Una struttura modulare facilita manutenzione, test, evoluzione e riutilizzo del codice.

------------------------------------------------------------------------

## D-004 — Gestione del repository

**Decisione**

Utilizzare GitHub come repository principale del progetto.

**Motivazione**

Garantisce versionamento, collaborazione e tracciabilità delle modifiche.

------------------------------------------------------------------------

## D-005 — Documentazione

**Decisione**

Documentare ogni Build e ogni decisione significativa.

**Motivazione**

La documentazione rappresenta parte integrante del progetto e consente di ricostruire facilmente l'evoluzione del software.

------------------------------------------------------------------------

# Stato

Documento inizializzato con la Build 0.1. Le decisioni future verranno aggiunte mantenendo la numerazione progressiva.
